# ADR-0001: 가격 시나리오 계산 기준

- 상태: Accepted
- 날짜: 2026-09-18
- 대체 문서: 없음

## Context

관심단지가 많아지면서 현재 가격 차이뿐 아니라, 가격이 같은 비율로 움직일 때 내 집과 관심단지의 격차가 어떻게 변하는지 비교할 필요가 생겼다.

가격 시나리오 표는 지역별 관심단지를 행으로 보여주고, 현재 가격을 중심으로 -30%부터 +30%까지 5% 단위의 변화를 표시한다. 이 계산은 실거래 기록이 월별로 여러 건 존재하거나 가격 종류가 서로 다를 수 있다는 점을 고려해야 한다.

## Decision

실제 시장에서는 동일 지역·유사 시점의 주택 가격이 개별 단지마다 차이는 있더라도 전체적으로 비슷한 비율로 상승하거나 하락하는 경향이 있다. 이 시장 움직임을 단순화해 확인할 수 있도록 내 집과 관심단지에 동일한 변동률을 적용한다.

각 시나리오에서 다음과 같이 계산한다.

```text
변동 후 내 집 가격 = 현재 내 집 가격 × (1 + 변동률)
변동 후 관심단지 가격 = 현재 관심단지 가격 × (1 + 변동률)
격차 = 변동 후 관심단지 가격 − 변동 후 내 집 가격
```

현재 가격은 선택된 가격 종류의 가장 최신 월을 찾은 뒤, 해당 월의 기록 중앙값을 사용한다. 내 집은 사용자가 선택한 가격 종류를 사용하고, 관심단지는 실거래가를 사용한다.

표의 지역 그룹화와 가격 계산은 화면 컴포넌트와 분리된 순수 함수에서 수행하며, 화면은 계산 결과를 표시하는 역할에 집중한다.

## Alternatives

### 관심단지 가격에만 변동률 적용

내 집 가격을 고정하면 관심단지 가격 자체의 상승·하락 폭은 보기 쉽지만, 시장 전체가 함께 움직이는 상황에서 두 자산의 격차 변화를 표현하지 못한다.

### 최신 단일 거래가 사용

가장 최근 거래 하나만 사용하면 직관적이지만, 같은 달의 여러 거래나 이상치에 민감하다.

### 평균값 사용

평균은 이상치의 영향을 크게 받을 수 있어, 거래량이 적은 단지의 현재 가격을 왜곡할 가능성이 있다.

## Consequences

- 같은 비율로 움직이는 상황에서 격차가 어떻게 변하는지 일관되게 비교할 수 있다.
- 중앙값을 사용해 같은 달의 일시적인 고가·저가 거래 영향을 줄일 수 있다.
- 가격 기록이 없는 단지는 시나리오 셀을 계산할 수 없으므로 별도 빈 상태로 표시한다.
- 최신 월이 서로 다르면 각 자산의 최신 기록 월을 기준으로 비교하게 된다.
- 이 계산은 예측 모델이 아니라, 현재 기록을 기준으로 한 단순 시뮬레이션이다.
