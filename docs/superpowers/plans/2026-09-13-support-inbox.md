# 문의함 및 운영자 답변 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자가 이미지가 포함된 문의와 운영자 답변을 앱 안에서 주고받고, 운영자는 별도 계정으로 모든 문의를 처리할 수 있게 한다.

**Architecture:** `support_tickets`를 문의의 원본으로 유지하고, 후속 대화는 `support_messages`, 파일 메타데이터는 `support_attachments`로 분리한다. 비공개 Supabase Storage 버킷에서 원본 이미지를 보관하고 signed URL로만 표시한다. GitHub Issue는 새 문의의 운영 추적용 복제본만 유지하며, 사용자 화면은 Supabase 데이터를 원본으로 표시한다.

**Tech Stack:** Next.js App Router, React, TypeScript, Supabase Auth/Postgres/Storage/RLS, Supabase JS, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-13-support-inbox-design.md`

## Global Constraints

- 일반 사용자는 Google·카카오 로그인만 사용한다.
- 운영자는 `/admin/login`의 이메일·비밀번호 로그인만 사용하며 `app_admins.user_id`로 권한을 판단한다.
- 모든 첨부 파일은 PNG, JPEG, WebP이고 최대 3개, 각 5MB다.
- `support-attachments`는 비공개 Storage 버킷이며 공개 URL을 만들지 않는다.
- 사용자 화면에서 GitHub, Issue 번호, GitHub URL을 표시하지 않는다.
- GitHub 토큰과 Supabase secret key는 서버에서만 사용한다.

```ts
export const attachmentTypes=['image/png','image/jpeg','image/webp'] as const;
export const maxAttachmentCount=3;
export const maxAttachmentBytes=5*1024*1024;
export type SupportStatus='open'|'answered'|'closed';

export function validateAttachment(file:{type:string;size:number}) {
 if(!attachmentTypes.includes(file.type as typeof attachmentTypes[number])) return 'PNG, JPEG, WebP 이미지만 첨부할 수 있습니다.';
 if(file.size>maxAttachmentBytes) return '이미지 한 개는 5MB 이하만 첨부할 수 있습니다.';
 return null;
}
export function validateAttachments(files:Array<{type:string;size:number}>) {
 if(files.length>maxAttachmentCount) return '이미지는 최대 3개까지 첨부할 수 있습니다.';
 return files.map(validateAttachment).find(Boolean)||null;
}
export const canReply=(status:SupportStatus)=>status!=='closed';
export const supportStatusLabel=(status:SupportStatus)=>({open:'접수',answered:'답변 완료',closed:'종료'}[status]);
```
