# 부동산 추가 기간 일괄 조회 설계

## 목표

관심단지를 여러 개 선택한 뒤 시작 월과 종료 월을 한 번만 입력해, 기존에 저장된 기간에 이어 실거래가를 일괄 조회·저장한다.

## 사용자 흐름

1. 보유·관심단지 화면에서 조회할 부동산 행의 체크박스를 선택한다.
2. 현재 지역 필터에 보이는 관심단지만 선택하거나 `전체 선택`으로 선택한다.
3. 선택된 단지 수와 함께 `전체 다시 조회` 버튼을 누른다.
4. 시작 월·종료 월을 입력하고 조회를 실행한다.
5. 선택된 단지와 월 조합별 진행상황을 안내하고, 완료 후 새 기록을 다시 불러온다.

## 범위와 정책

- 대상은 `owned === false`인 관심단지만이다.
- 지역 필터가 적용된 상태에서는 현재 보이는 관심단지만 일괄 선택 대상이다.
- 기존 `syncMonths`의 월 범위 검증과 `runTradeSync`의 동시성 제한·부분 실패 집계를 재사용한다.
- 종료 월은 한국 시간의 현재 월을 넘을 수 없고, 한 번의 요청은 단지×개월 기준 1,200건까지 허용한다.
- 클라우드 로그인 상태에서만 실거래 API를 호출한다. 데모·로컬 모드에서는 로그인 안내를 표시한다.
- 기존 기록과 같은 단지·월을 다시 조회해도 저장 계층의 upsert 정책으로 중복을 만들지 않는다.
- 성공한 단지의 기록은 저장하고, 실패한 단지는 실패 목록과 함께 사용자에게 알린다.

## UI 방향

- 단지 목록 헤더에 선택 개수, `전체 선택`, `선택 해제`, 일괄 조회 버튼을 배치한다.
- 각 관심단지 행 왼쪽에 체크박스를 둔다. 보유 부동산에는 체크박스를 두지 않는다.
- 일괄 조회 창은 기존 단일 조회 창과 같은 월 선택 컴포넌트를 사용한다.
- 진행 중에는 실행 버튼과 선택 체크박스를 비활성화하고 현재 처리 상태를 메시지로 보여준다.
